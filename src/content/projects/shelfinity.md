description: A self-hosted library management system for catalog browsing, borrowing, and approval workflows.
longDescription: >
  Shelfinity handles the day-to-day of running a library — browsing a catalog,
  requesting a book, reserving one that's out, and tracking overdue returns —
  behind a single approval queue for registration and borrowing requests.
  Identity is handled entirely by Keycloak, so the application never stores a
  password. The backend is a Jakarta EE service on Maven with a PostgreSQL
  database; the frontend is a React application. The project ships with
  Testcontainers-based integration tests, a Playwright and Jest suite, and a
  documented API and business-rules spec that's checked against the running
  codebase rather than left to drift.
